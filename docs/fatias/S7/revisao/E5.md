## Como foi feito
- **Telas:** reais, capturadas em produção por script Playwright (Portal a 1280×720 com escala 1,5; celular a 390 px). Os e-mails exibidos são trocados na tela por `dono@exemplo.com` / `cliente@exemplo.com` (D319), e os clientes são de teste (`@exemplo.invalid`).
- **Cenas:** abertura com o desafio → problema (landing) → cardápio → pacote proposto pela IA → kit → cliente no celular (benefício + convite) → garçom → painel do restaurante de exemplo → plano da semana → assistente (antes → depois) → "Como funciona" → fecho.
- **Narração:** Piper, voz pt-BR *faber* (medium), local e sem chave, escolhida pelo candidato entre 4 amostras. O texto da fala tem grafias fonéticas para siglas e marca ("quiú-ár", "ai fúd").
- **Legendas:** embutidas (ASS a 1920×1080), uma frase por vez, com selo permanente no canto superior esquerdo: "Protótipo de case · não é produto oficial do iFood · telas reais, e-mails ocultados".
- **Montagem:** ffmpeg, com zoom suave (até 2%) em cada tela.
- **Animação 3D:** não entrou (D312: prazo de 2 h, só se sobrar tempo).
